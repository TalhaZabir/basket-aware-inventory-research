# Phase 8 quality-gate report

The package passes the core reproducibility and evidence-boundary checks: raw and processed data are present, scripts and configurations are stored, the Phase 1 and Phase 2 test replays are logged, duplicate Phase 1 execution is disclosed, and the Phase 2 test guard prevents a second frozen replay. Figures and tables are generated from result files, and no UCI inventory, supplier, stockout, or cost field is fabricated. The final DOCX has zero high, medium, or low accessibility findings in the generated audit; visual rendering was attempted but the bundled environment did not provide LibreOffice, so a full PNG render gate remains an environment limitation.

The following gates remain partial or open: a single make-all script does not yet regenerate every manuscript object in one command; no automated text-to-CSV number checker is present; authenticated Scopus/Web of Science screening plus a full DOI-resolution audit remain unavailable; and a public project repository cannot be created without a destination and authenticated remote. The Phase 3 precision targets and second basket pipeline are now complete as documented, with the external replay explicitly non-discriminating.

**Decision rule:** the main dataset does not establish a graph-specific economic advantage. In the primary Phase 3 replay, PA1 improves service relative to the matched independent control but is worse than C4 popularity-only; placebo contrasts are mixed and rolling windows are not uniform. The manuscript therefore follows the conditional negative branch: basket-aware buffering can improve simulated service under one control, but the evidence does not show that basket topology adds value beyond popularity allocation.

# Cover letter

Dear Editor,

Please consider the manuscript “Does Basket Structure Add Value Beyond Popularity in Multi Item Replenishment?” for publication. The paper studies whether a transaction-derived co-purchase graph improves multi-item replenishment once inventory is matched and popularity is controlled.

Using UCI Online Retail II, we construct a training-only basket graph, compare a graph-buffer policy with an inventory-matched independent control and a popularity-only control, and replay the policies across a factorial set of lead-time and cost conditions. The main result is deliberately narrower than a claim of universal graph value: the graph policy does not improve service over popularity at matched inventory in the primary all-cell analysis. An exploratory low-popularity/high-lift stratum shows a conditional service gain, while a high-popularity stratum does not. These results support a practical rule for using graph information only when it identifies under-served products that popularity misses.

The manuscript distinguishes observed transaction facts from simulated inventory assumptions, reports scenario-level uncertainty, and supplies reproducible code and data-preparation materials. The dunnhumby analysis is retained as a pipeline stress check rather than presented as replication, because its complete-basket proxy does not discriminate and its inventory records are unavailable.

This manuscript is not under consideration elsewhere. All authors have approved the submission.

Sincerely,

The authors
